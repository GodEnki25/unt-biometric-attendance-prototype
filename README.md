# UNT Biometric Attendance Prototype

This project explores a consent-driven biometric attendance system designed for academic classroom environments at the University of North Texas.

## Design Principles
- Explicit student opt-in and revocable participation
- Human-in-the-loop attendance verification
- No raw biometric image storage
- Privacy-aware system architecture
- Canvas LMS synchronization (prototype)

## Planned Architecture
- /frontend: Instructor and student web interface
- /backend: API services and Canvas integration
- /ml: Biometric recognition pipeline
- /docs: Project charter, vision, and design notes
